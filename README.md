# Optimization-Based User Scheduling for Multiuser MIMO Systems

MATLAB simulation code for the numerical experiments in:

> V. Palhares and C. Studer, **"An Optimization-Based User Scheduling Framework for Multiuser MIMO Systems,"** *IEEE Trans. Wireless Commun.*, Nov. 2026, doi: [10.1109/TWC.2026.3754543](https://doi.org/10.1109/TWC.2026.3754543).

The simulator evaluates optimization-based user scheduling together with the baseline scheduling methods used in the paper for centralized millimeter-wave (mmWave) massive MU-MIMO and sub-6-GHz cell-free massive MU-MIMO systems.

## Branches

The `main` branch contains the frequency-flat time-scheduling simulations used for Scenarios S1-S6 and the additional T = 8 mmWave experiment reported in the paper.

This `frequency-selective` branch contains the frequency-selective OFDM scheduling simulation reported in Table V. The simulator on this branch directly uses one channel matrix `H(:,:,t)` for each of the eight frequency slots.

## Frequency-selective experiment

This branch reproduces the frequency-selective OFDM experiment reported in Table V. The configuration uses `B = 32`, `U = 64`, eight frequency slots, `Umin = 8`, `Umax = 10`, `Tmin = 1`, and `Tmax = 4`. The internal scenario code is `d`, and the number of frequency slots is set by `par.frequency_slots`.

The scheduling methods are:

- Random
- MSE-LMMSE (`MMSE`)
- Channel capacity (`Capacity`)
- Achievable rate (`Rate`)
- SUS
- CSS
- Greedy
- AUA (`No Scheduling`)
- LoFi (`K=1`)
- LoFi (`K=4`)

For the frequency-flat time-scheduling simulations, use the `main` branch.

## Frequency-selective channel files

Each channel file must contain a three-dimensional channel array `H` with one matrix per frequency slot. For this experiment, `H` has size `32 x 64 x 8`.

The channel loader follows the naming convention used by the original frequency-selective implementation:

```text
<channel-root>/mmwave_32_64_QuadMMLoS_100MHz/channels_mmwave_32_64_freq_sch_<channel_id>.mat
```

## Requirements

- MATLAB R2021b or a compatible newer release.
- MATLAB functionality providing `de2bi`, `randsample`, and `dftmtx`.
- Frequency-selective channel MAT files with `H` of size `32 x 64 x 8`.
- Sufficient storage for the per-job result MAT files generated by the Monte Carlo simulations.

The paper simulation uses 1,000 channel realizations and 100,000 Monte Carlo trials per channel realization.

## Paths to configure before running

### 1. Channel MAT-file path

Edit **line 22** of:

```text
Main_simulator/channel/gen_channel.m
```

The current line begins with:

```matlab
FileLoad=['/path/to/channel/',par.system_type,'_',num2str(par.B),'_',...
```

Replace only `/path/to/channel/` with the directory containing the `mmwave_32_64_QuadMMLoS_100MHz/` channel folder. Keep the remainder of the filename construction unchanged.

For example, if the channel folder is under `/data/ue_scheduling/channels/`, use:

```matlab
FileLoad=['/data/ue_scheduling/channels/',par.system_type,'_',...
```

### 2. Simulation result path

Edit **line 374** of:

```text
Main_simulator/main_function.m
```

The current line is:

```matlab
path_to_save = (['/path/to/results/']);
```

Replace `/path/to/results/` with the directory where the per-job result MAT files should be written. The path should end with `/`.

The generated filenames have the form:

```text
USER_SCHEDULING_mmwave_32_64_T_8_<process_id>.mat
```

### 3. Post-processing paths

In:

```text
mmwave/32_64_T_8_Tmax_4_freq_sch/start_results.m
```

set:

- **line 24**: `par.main_path` to this repository's `Main_simulator/` directory;
- **line 29**: the path passed to `plot_figures_cdf` to the directory containing the frequency-selective result MAT files.

Channel and result MAT files are intentionally not tracked by Git.

## MATLAB path setup

Start MATLAB from the repository root and add this branch's simulator to the MATLAB path:

```matlab
addpath(genpath(fullfile(pwd,'Main_simulator')),'-begin');
```

Then move to the frequency-selective experiment directory:

```matlab
cd('mmwave/32_64_T_8_Tmax_4_freq_sch');
```

## Running one simulation job

The frequency-selective entry point accepts a zero-based process ID. To run process 0:

```matlab
main_sim_code(0);
```

The process ID selects the channel realization and scheduling method automatically.

## Running all jobs

To run the complete frequency-selective experiment:

```matlab
par.plot_type = 'CDF';
par.system_type = 'mmwave';
par.sim_scenario = 'd';
par = param_config(par);

for proc_ID = 0:par.total_jobs-1
    main_sim_code(proc_ID);
end
```

For large experiments, the process IDs can be distributed across independent MATLAB workers or compute nodes because each process writes a separate result file.

## Generating figures and percentile summaries

Configure the two paths in `mmwave/32_64_T_8_Tmax_4_freq_sch/start_results.m`, create a `figures` directory if needed, and run:

```matlab
mkdir('figures');
start_results;
```

The post-processing functions in `Main_simulator/results/` aggregate the per-job MAT files and generate the CDF/CCDF outputs.
